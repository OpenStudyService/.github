# OpenStudy

**스터디카페 지점 운영을 하나로 묶은 팀 운영 워크스페이스**

사장님·지점 관리자·직원이 고객·이용권·결제, 좌석·스터디룸·사물함, 업무·채팅, 근무·근태, 매출을 한 서비스에서 관리합니다. 자연어로 질문하면 운영 데이터를 표와 차트로 보여 주는 AI 분석도 제공합니다.
